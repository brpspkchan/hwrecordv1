執行全校升級後，學生班別將自動往上升級（如 1A $\rightarrow$ 2A，6 年級轉為畢業生），且本學期的所有欠交紀錄將會自動結算並歸檔至歷史資料庫。

注意事項：

1. 升級前建議先將本學期欠交報表匯出備份。

2. 此操作無法復原，請確保全校期末成績與紀錄皆已結算完畢。

Google Apps Script 試算表設定指南

設定步驟：

  1. 開啟您的 Google 試算表，點擊選單列的 「擴充功能」 $\rightarrow$ 「Apps Script」。
  2. 將以下程式碼貼入腳本編輯器中（覆蓋原始 `Code.gs` 的內容）。
  3. 點擊右上方 「部署」 $\rightarrow$ 「新建部署」。
  4. 種類選擇 「網頁應用程式 (Web App)」。
  5. 誰可以存取 (Who has access) 必須選擇：「所有人 (Anyone)」。
  6. 完成部署後複製「網頁應用程式 URL」，並貼至 Admin 管理者後台的設定欄位中。

Google Apps Script 原始碼 (僅寫入：班別、姓名、欠交日期)：

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // 若工作表為空，自動建置表頭
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["班別", "姓名", "欠交日期"]);
      sheet.getRange(1, 1, 1, 3).setFontWeight("bold").setBackground("#f3f4f6");
    }
    
    var data = JSON.parse(e.postData.contents);
    
    // 批次寫入所有欠交學生紀錄
    if (Array.isArray(data) && data.length > 0) {
      data.forEach(function(row) {
        sheet.appendRow([row.className, row.studentName, row.date]);
      });
    }
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success", count: data.length }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
